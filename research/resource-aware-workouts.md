# Home-resource workout design notes

RootedFit should use resources as meaningful training inputs rather than showing generic equipment notes.

For a selected chair, use a stable, non-wheeled chair on a non-slip surface, and offer supported sit-to-stands, wall or chair incline presses, calf raises, and controlled seated mobility. These selections follow the NHS strength-exercise guidance, which also emphasises gradual progression.

For a selected resistance band, make bands change the exercise list through standing-on-the-band or looped-around-the-feet variations. In the app’s general-wellness framing, instructions must ask the user to inspect the band, move slowly, avoid jerking, and never release it under tension. These are drawn from ACE’s resistance-band guidance.

For filled bottles or weights, use controlled loaded hinges, presses, carries, and rows only where the user has selected that resource. For no equipment, retain bodyweight and small-space movements. Outdoor routes, stairs, skipping ropes, safe floor space, and mats should each select a matching cardio, core, mobility, or recovery variation.

Follow-along recommendations should only be presented as an actionable streaming option when the user selected internet access for video workouts. Otherwise, RootedFit should foreground the self-guided plan and explain that the session was built to run without streaming.

## Verified optional demonstrations

- **Chair:** [Full Body Chair Workout](https://www.youtube.com/watch?v=gD14hSNBT7M) from East London NHS Foundation Trust. The video describes a beginner-friendly full-body chair session and calls for a sturdy chair.
- **Resistance band:** [15 min Resistance Band Workout — Full Body Routine](https://www.youtube.com/watch?v=tONvKzIiqqw) from fitbymik. The video description calls for a light-to-medium handled resistance band.
- **Water bottles:** [Full Body Water Bottle Workout — At Home](https://www.youtube.com/watch?v=bGXIt8zR3os) from Coach Mere. The video is used as an optional demonstration only for users who select weights or filled bottles.
